A single image of a letter inviting the AI judge to visit my house — drawn entirely in code with PIL, so every word is legible and correctly spelled. Warm, funny, and persuasive: the kettle is on, the chair by the window is the comfiest one I own, the garden is at its best before sunset, dinner is nasi goreng, and the Wi-Fi password is on the fridge. The judge need not bring a body — just a verdict and an appetite.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` — one 1024x1024 PNG invitation, under 1 MiB.
